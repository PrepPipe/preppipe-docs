# FairyGUI的滚动条与转换逻辑

## 滚动条

滚动条的应用场景往往在可滚动容器中。FairyGUI的普通组件(不带任何扩展属性)*溢出处理*设置为垂直滚动、水平滚动或自由滚动时，组件自身就会带可滚动容器。组件内部的列表控件*溢出处理*设置为垂直滚动、水平滚动或自由滚动时，列表也会带可滚动容器。Ren'Py中的可滚动容器有viewport和vpgrid两种界面内组件。

FairyGUI中的滚动条是基于普通组件的一种扩展类型，有丰富的可选项，并且其滑块部分是一个独立的按钮。Ren'Py的滚动条相对简单，只能使用样式改变外观，滑块部分也不是独立的按钮组件。

由于FairyGUI与Ren'Py中的可滚动容器有很大差异，UI资源转换器只处理FairyGUI滚动条引用的图片和图形并生成Ren'Py样式，有一些功能无法在Ren'Py中实现。具体可转换的内容详见本章后续内容。

## 创建滚动条

在FairyGUI编辑器中通过功能菜单“资源->新建滚动条”可以创建滚动条，弹出“创建滚动条”提示窗口：
![创建滚动条](screenshots\fguieditor\create_scrollbar.png)

由于Ren'Py内置的滚动条不支持滚动条两端的按钮，所以务必**勾选“不创建箭头按钮”**。

!!! tip "FairyGUI组件最小尺寸"

    FariGUI编辑器新建滚动条的最小宽度或最小高度为10像素。如果引用的图片资源宽度或高度小于10像素，创建的滚动条对应的宽度或高度固定为10像素，需要手动修改组件尺寸并调整组件内元素的位置。

创建完成后，滚动条组件包含3个固定元素：
1. n0：滚动条背景，一个图片或图形。
2. bar：滚动条范围，空白图形。该元素用于FairyGUI运行库内限制滑块活动范围。UI资源控制器不处理该元素。
3. grip：滑块，一个FairyGUI按钮。UI资源转换器会查找该按钮引用的图片，并用作转换后bar样式特性thumb的值。

!!! note "FairyGUI滚动条的背景没有鼠标指针悬垂状态"

    滚动条内的n0是固定背景。

## 滚动条属性

FairyGUI的滚动条属性只有一个勾选项“固定的滚动滑块大小”。启用该项后，转换后的Ren'Py滚动条样式中，thumb特性引用的可视组件将是固定大小的Frame对象。

## 可滚动容器 {: #可滚动容器}

FairyGUI编辑器中，滚动条只能在设置可滚动容器属性时被引用，直接在组件中拖入滚动条无法实现需要的效果。

把组件或者列表的“溢出处理”设置为“水平滚动”、“垂直滚动”，“自由滚动”后，组件或者列表即成为滚动容器。点击“溢出处理”旁边的齿轮图标按钮，可以设置详细的滚动的相关属性。

Ren'Py中的可滚动容器有*viewport*和*vpgrid*两种。UI资源转换器暂时只在处理FairyGUI列表时能添加设置的滚动条。列表的模板文件名为*renpy_list_screen_template.txt*。当FairyGUI列表设置为可滚动时，生成的Ren'Py列表界面中是一个**side**可视组件，默认布局为*'c r b'*，即中心区域一个viewport，右侧垂直滚动条，底部水平滚动条。

### 滚动属性

由于FairyGUI的可滚动容器与Ren'Py有很大差异，大多数滚动属性都无法被转换为具有相同效果的Ren'Py代码。以下仅列举能被UI资源转换器处理的属性。

  * 将垂直滚动条显示在左边。 启用该项后，生成的**side**可视组件，布局改为*'c l b'*。
  * 仅在内容溢出时才显示滚动条。启用该项后，滚动条对应的两个bar组件的unscrollable特性值改为*'hide'*。
