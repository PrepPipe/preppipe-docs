# FairyGUI的进度条与转换逻辑

## 进度条

进度条常用于展示某个变量，并且不能直接使通过自身更改该变量。

FairyGUI中的进度条不具可互动性，不支持鼠标点击和拖动操作，只有水平方向一种形式。

Ren'Py中的不具有*thumb*样式特性的bar具有类似的展现效果。

目前UI资源转换器只处理FairyGUI进度条引用的图片和图形，生成的Ren'Py样式，效果与FairyGUI略有差异。具体可转换的内容详见本章后续内容。

## 创建进度条

在FairyGUI编辑器中通过功能菜单“资源->新建进度条”或快捷按钮可以创建进度条，弹出“创建进度条”提示窗口：
![创建滚动条](screenshots\fguieditor\create_progressbar.png)

其中的“标题类型”不会被UI转换器处理。我们建议需要显示进度条关联数值的组件中使用独立的标签组件或文本控件，在FairyGUI中设计文本样式，转换为Ren'Py代码后手动将固定文本改为变量相关的表达式。

!!! tip "FairyGUI组件最小尺寸"

    FariGUI编辑器新建进度条的最小宽度或最小高度为10像素。如果引用的图片资源宽度或高度小于10像素，创建的进度条对应的宽度或高度固定为10像素，需要手动修改组件尺寸并调整组件内元素的位置。

创建完成后，进度条组件包含2个固定元素：
1. n0：进度条背景，一个图片或图形。
2. bar：进度条前景，一个图片或图形。表示进度条对应变量生效的值。

### 前景图片的差异

与滑动条类似，FairyGUI对前景的处理方式为缩放，Ren'Py对前景的默认处理方式为剪裁。

为了尽量使FairyGUI编辑器预览效果与转换后的Ren'Py运行结果一致，UI资源转换器会根据进度条的前景和背景图片生成Ren'Py中的Frame对象，并将bar的*bar_resizing*样式特性值改为True。

缩放和剪裁两种方式在实际的不同游戏项目中都可能用到。若需要进度条前景使用剪裁，请在生成的bar样式中手动将*bar_resizing*的值改为False。

### 进度条属性

FairyGUI的进度条属性只有一项，与标题相关。UI资源转换器不处理，可以忽略。

### 鼠标事件与关联变量

FairyGUI中的进度条不接受任何鼠标事件。Ren'Py中的bar在关联对象为*ui.adjustment*对象且该对象的*adjustable*属性为False时，不接受鼠标操作修改关联对象的值。

因此，UI资源转换器在处理FairyGUI发布资源的进度条时，如果该进度条没有自定义数据部分，则会在界面内生成一个*ui.adjustment*类型的变量，并设置为bar*adjustment*特性的值。

!!! warning 关联变量的最小值必须为0

    Ren'Py中的ui.adjustment对象取值范围为从0到任意正数。FairyGUI中设计进度条时请务必保证最小值为0，最大值为正数。
    若在FairyGUI编辑器中设置了进度条的自定义数据，该数据将直接用作转换后的ui.adjustment类型变量名。需要在Ren'Py项目的其他脚本中声明该变量，否则运行会报错。
