# FairyGUI的按钮与转换逻辑

## 按钮

按钮是所有GUI中最常见的一种组件。FairGUI中按钮的设计与实现方案与Ren'Py有一些差异。
UI资源转换器目前只处理简单按钮，即图片和文字为主要元素的按钮。

## 创建按钮

在FairyGUI编辑器中通过功能菜单“资源->新建按钮”或快捷按钮可以创建按钮，弹出“创建按钮”提示窗口：
![创建按钮](screenshots\fguieditor\create_button.png)

我们不推荐将其他组件在组件属性里选择扩展为“按钮”的方式。因为，如果该组件缺少必要元件，UI资源转换器可能无法将其正确地转为Ren'Py代码。

### 按钮尺寸

除非明确需要将按钮的某些空白区域也设为可点击区域，否则建议选择“自动大小”，可以根据按钮使用的图片自动计算新按钮的尺寸。
如果按钮不同状态显示的图片尺寸不同，创建按钮时的尺寸会与尺寸最大的那张图片一致。其他图片默认在左上角对齐。

建议在美术素材层面，用于按钮不同状态的图片保持尺寸统一。与按钮尺寸不一致的图片，也可以在按钮的编辑窗口中调整位置。

### 图片设置

1. 正常状态图片。按钮控制器*0:up*时显示的图片。对应Ren'Py样式特性中的*idle_background*。

2. 按下状态图片。按钮控制器*1:down*时显示的图片。如果按钮是单选或复选按钮，对应Ren'Py样式特性中的*selected_idle_background*；如果按钮是普通按钮，没有对应的Ren'Py样式特性，UI资源转换器生成的Ren'Py按钮无法在鼠标按下后显示FairyGUI中设置的图片。

3. 鼠标悬浮时图片。按钮控制器*2:over*时显示的图片。对应Ren'Py样式特性中的*hover_background*。

4. 按下状态鼠标悬浮时图片。按钮控制器*3:selectedOver*时显示的图片。如果按钮是单选或复选按钮，对应Ren'Py样式特性中的*selected_hover_background*；如果按钮是普通按钮，没有对应的Ren'Py样式特性UI资源转换器生成的Ren'Py按钮无法在鼠标按下后显示FairyGUI中设置的图片。

### 按钮模式

FairyGUI编辑器中不同模式的按钮仅用于预览。转换为Ren'Py代码的按钮是否符合对应效果，取决于按钮绑定的行为是什么。如果多个按钮绑定同一个变量(例如preferences中一些变量)，且设置的值互斥，这些按钮就是同一个组内的单选按钮。如果按钮绑定了一个布尔型变量且唯一，该按钮就是一个复选按钮。如果按钮绑定的行为是某些无返回结果的函数，该按钮是一个普通按钮。

在FairyGUI编辑器中，按钮的“自定义数据”为空，则转换后的按钮默认为普通按钮。

### 按钮标题

勾选*创建文本标题*后，FairyGUI编辑器中创建的按钮默认带一个名为“title”的文本控件。勾选*创建图形标题*后，FairyGUI编辑器中创建的按钮默认带一个名为“icon”的装载器控件。

UI资源转化器会将title控件转为Ren'Py按钮界面中的text组件，并生成对应的文本样式。

UI资源转换器目前只能处理icon装载器中的图片。如果icon装载器中引用的是其他类型控件或其他组件将，转换后的Ren'Py可能会出现运行时报错。

我们建议在FairyGUI编辑器中设计按钮时，直接设置不同按钮状态显示不同的图片，而不通过icon装载器+属性控制“图标”的方式。虽然后者在有FairyGUI运行库的游戏引擎上也是可行的做法，但语涵编译器的UI资源转换尚无法处理。

## 按钮设计

在创建按钮阶段，设置完按钮不同状态下显示的图片，就已完成按钮的大部分设计工作。还有少量可选的设计工作在FairyGUI编辑器中完成。

![按钮属性](screenshots\fguieditor\button_attributes.png)

### 按钮属性-点击音效

可以从FairyGUI编辑器的资源库中拖拽一个音频文件到*点击音效*输入框。UI资源转换器会在设置为Ren'Py按钮界面代码的*activate_sound*特性。
FairyGUI中设置的按钮音量设置仅用于预览，Ren'Py不支持针对单个按钮的音量设置。

### 按钮属性-按下效果

FairyGUI中的按钮按下效果与按下状态显示的图片是两个独立的效果。**按下效果**只有无(效果)、变暗和缩放3种。

如果在FairyGUI中设置按钮*按下效果*为变暗或缩放，UI资源转换器生成的按钮结果代码中，button组件的父组件将会是一个Ren'Py中的cdd：*button_container*。该cdd定义在 01_renpy_cdd.rpy 文件中。button_container可能有*pressed_dark*或*pressed_scale*两种自定义样式之一，分别对应变暗与缩放。

!!! warning "设置按下效果的按钮可能导致的问题"

    按下效果通过cdd实现，对Ren'Py鼠标事件的处理可能存在问题。目前已知在列表中使用这样的按钮，在按下按钮并拖动列表时出现按钮显示结果无法回到idle状态的问题。

### 组件属性-点击测试

如果需要按钮中某些透明区域不响应鼠标点击，可以在FairyGUI中设置*点击测试*属性。该输入框一般只能是组件内显示列表中的某个图片或图形，对应Ren'Py中的*focus_mask*特性。

!!! tip

    FairyGUI中由于点击测试的显示元素并不会强制隐藏。如果想用一个矩形来限制按钮的可点击区域，建议把该图形放在显示列表的最底层(即FairyGUI显示列表的第一个元素)，被其他显示元素挡住。

### 其他属性-自定义数据

按钮的自定义数据将用作按钮的行为(action)。例如，某按钮的自定义数据设置为 *Start()* ，转换后引用该按钮时会将该值作为actions参数的值传入按钮界面:
>use main_menu_button_new(actions=Start())

## FairyGUI编辑器舞台的按钮属性

在其他普通组件的编辑舞台中，可以直接拖入设计完成的按钮组件，生成一个按钮实例。FairyGUI的按钮实例具有按钮实例属性。
![按钮实例属性](screenshots\fguieditor\button_instance_attributes.png)

按钮实例属性的标签与设计按钮时设置的*模式*有关。如果按钮模式是“普通按钮”，实例属性的标签就是“普通按钮”。上图的按钮，模式是“单选按钮”，所以标签也是“单选按钮”。

目前只有部分按钮实例属性可以被UI资源转换器处理并在生成的Ren'Py代码中生效。因此按钮的可复用性相比FairyGUI原本设计的可复用性降低了一些，有些时候不同的按钮实例需要单独设计不同的按钮组件。

### 状态

此勾选项仅用作预览。Ren'Py中的按钮是否处于选中(selected)状态，取决于绑定行为后的具体变量。

### 标题

如果按钮内部有名为*title*的文本控件，那直接修改按钮实例属性中的标题后，按钮显示的文本也会发生改变。此项对应转换后Ren'Py按钮界面定义中的*title*参数。

### 选中时标题

此项不会被UI资源转换器处理。

### 标题颜色和字体大小

这两项不会被UI资源转换器处理。

### 图标

仅处理使用图片作为图标的情况。此项对应转换后Ren'Py按钮界面定义中的*icon*参数。

### 选中时图标

此项不会被UI资源转换器处理。

### 点击音效

此项对应转换后Ren'Py按钮界面定义中的*activate_sound*参数。*音量*不会被UI资源转换器处理。

### 连接

如果组件内设置了控制器，可以通过组件内的按钮修改控制器当前索引。关于控制器的部分详见[控制器](./ui_component_controller.md)。

UI资源转换器会将FairyGUI组件中的控制器转为Ren'Py界面内的变量，按钮的连接属性被转换后变为对界面内变量的设置。
比如preferences界面中用于切换配置选项的按钮，转换后可以得到如下代码：
> use audio_tab_button(actions=[SetScreenVariable('tab_controller', 0)])

!!! note "按钮是否被选中状态的差异"

    Ren'Py中如果不使用按钮特性*selected*判断某个按钮是否处于被选中的情况下，会默认使用行为(action)来决定按钮是否被选中。当按钮被点击并执行绑定行为后，如果修改了某些变量，则当前点击按钮必定会处于选中状态。其他会修改相同变量的按钮，则必定会处于idle状态，除非这些按钮修改变量的结果相同。比如，按钮audio_tab_button的点击行将界面内变量tab_controller修改为0，按钮text_tab_button的点击行为将界面变量tab_controller修改为1，这两个按钮的状态就是互斥的，点击其中一个都是使另一个变为idle状态。
    FairyGUI不强制按钮状态与连接的控制器关联，模式为“普通按钮”的按钮也可以连接某个控制器索引，点击之后依然处于正常状态而不是按下状态。

## 自定义数据与Ren'Py中的行为

FairyGUI的所有组件都预留了自定义数据属性。UI资源资源转换器会处理按钮的自定义数据内容，并用作Ren'Py中按钮的点击行为(action)。

此设计可以在UI设计层面就指定常用组件的实际功能，用户不需要转换为Ren'Py代码后再查找对应的按钮代码并修改具体功能，也避免了修改UI重新发布和转换后覆盖actions的问题。

自定义数据可以是包含多个行为的字符串，各行为使用英文逗号分隔，但**不要在最外层添加方括号**写成Python列表形式。例如，我们需要某个按钮修改变量flag的值并同时在通知消息窗口显示一段文字，可以在按钮的自定义数据输入：

> SetVariable('flag', True), Notify('Flag was set to True')

转换器会自动把这段内容以列表形式绑定为按钮的行为。如果按钮同时还负责某个FairyGUI控制器的索引，转换后的按钮行为列表中还会添加一条修改界面内变量的内容。
