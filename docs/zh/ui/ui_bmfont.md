# 位图字体

## FairyGUI中的位图字体

FairyGUI编辑器中具有“新建字体”功能，通过导入的图片资源并根据需要进行设置创建位图字体。也可以使用外部位图字体制作工具BMFont、ShoeBox等生成合适的字体文件并导入编辑器。具体说明请参考 <https://www.fairygui.com/docs/editor/font#位图字体> 。

导出资源时，FairyGUI并不以“.fnt 文件 + 单独字体纹理”的形式生成位图字体，而是把字体控制文件的主要内容写在资源描述文件中，字体用到的纹理可能分布在多个atlas纹理集中。

## Ren'Py中使用位图字体

Ren'Py可以使用“.fnt 文件 + 字体纹理”形式的位图字体，需要在任意脚本的初始化阶段使用 *renpy.register_bmfont* 函数注册。
使用外部位图字体制作工具生成的字体直接放在Ren'Py项目的合适位置，并自行注册也是可行的使用方式。

!!! warning
    Ren'Py的某些版本对位图字体的支持有问题。目前已知8.3可以使用，8.4运行时报错，8.5可使用但字体渲染颜色错误。

## 使用UI资源转换器生成位图字体

UI资源转换器会根据资源描述文件中的信息，在目标Ren'Py项目的 **fonts** 目录中生成 .fnt 字体控制文件，在 **images** 目录中生成单独的位图纹理，在 **scripts/01_bmfont_registration.rpy** 文件中注册FairyGUI发布资源时使用的字体名。

由于Ren'Py要求位图字体中必须包含空格(字符编号32)，否则在运行时报错。UI资源转换器生成的位图字体控制文件会添加空格字符信息，生成的纹理尺寸可能会比原生的纹理大一点点，右下角的透明像素用作空格。
