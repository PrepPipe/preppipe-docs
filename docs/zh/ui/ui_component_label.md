# FairyGUI的标签与转换逻辑

## 标签

标签是FairyGUI中的一种简单组件。若标签内存在名为icon的装载器和名为title的文本时，引用标签的组件可以通过标签属性设置标签的显示内容。
标签与按钮类似，但自身默认不具有控制器，也不接受点击事件。

UI资源转换器目前只处理部分简单标签，即icon中使用图片的标签。

## 创建标签

在FairyGUI编辑器中通过功能菜单“资源->新建标签”或快捷按钮可以创建标签。

我们不推荐将其他组件在组件属性里选择扩展为“标签”的方式。因为，如果该组件缺少必要元件，UI资源转换器可能无法将其正确地转为Ren'Py代码。

新创建的标签内只有一个名为“title”的文本元件。我们可以自行创建名为“icon”的装载器，作为整个标签组件的背景。

UI资源转换器目前只支持文本类型的“title”，不支持富文本和输入文本。
UI资源转换器目前只支持装载器类型的“icon”，不支持其他标签或按钮。

!!! tip "请注意标签内元件顺序"
    新建“icon”装载器处于整个组件显示列表最顶层，可能会盖住title文本，需要手动调整显示列表中的元件顺序。

## 标签设计

标签本身没有任何独特属性。FairyGUI编辑器中的“制作说明”中的closeButton、dragArea和contentArea用于**窗口框架**。
可以在标签中添加任意组件和元件，但不会在转换后得到的Ren'Py项目中获得交互效果。

## FairyGUI编辑器舞台的标签属性

在其他普通组件的编辑舞台中，可以直接拖入设计完成的标签组件，生成一个标签实例。FairyGUI的标签实例具有标签实例属性。

![按标签实例属性](screenshots\fguieditor\label_attributes.png)

### 标题

如果标签内部有名为*title*的文本控件，那直接修改实例属性中的标题后，标签显示的文本也会发生改变。
此项对应转换后Ren'Py标签界面定义中的*title*参数。

### 标题颜色

指定标签实例中*title*文本的颜色。

### 字体大小

指定标签实例中*title*文本的字号。

### 图标

UI资源转换器仅处理使用图片作为图标的情况。此项对应转换后Ren'Py界面定义中的*icon*参数。

### 点击音效和音量

UI资源转换器不处理这两项。
