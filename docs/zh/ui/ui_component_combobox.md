# FairyGUI的下拉框与转换逻辑

## 下拉框

下拉框在初始状态下是一个按钮，点击后会在该按钮上方或下方显示一个列表，列表内的元素是若干按钮。
点击列表内的按钮，将修改下拉框按钮的标题文字，并隐藏按钮列表。点击空白处也可以隐藏按钮列表。

下拉框可以看作是多个互斥单选按钮的组织形式，但比始终显示多个按钮的方式节省UI显示控件。

Ren'Py中不具有原生的下拉框组件。
UI资源转换器会根据FairyGUI的下拉框生成一个具有相似功能的界面，可以在其他界面中使用use语句引用此界面。具体可转换的内容详见本章后续内容。

## 创建下拉框

在FairyGUI编辑器中通过功能菜单“资源->新建下拉框”或快捷按钮可以创建下拉框，弹出“创建下拉框”提示窗口：
![创建下拉框](screenshots\fguieditor\create_combobox.png)

根据提示逐步设置各部分的图片资源即可创建。

我们不推荐将其他组件在组件属性里选择扩展为“下拉框”的方式。因为，如果该组件缺少必要元件，UI资源转换器可能无法将其正确地转为Ren'Py代码。

创建下拉框后会自带两个前缀与下拉框同名的组件，分别为后缀为“popup”的组件和后缀为“item”的按钮，分别表示点击下拉框后显示的列表和列表中的按钮元素。
例如，创建名为“TestComboBox”的下拉框后，会同时创建“TestComboBox_popup”组件和“TestComboBox_item”按钮。

!!! tip "FairyGUI编辑器中预览下拉框"

    FariGUI编辑器中打开已创建的下拉框并运行测试后，仅能看到按钮的点击效果，无法看到popup组件和item按钮。需要在其他组件的舞台编辑模式下引入下拉框实例，再测试运行该组件才能看到完整的下拉框效果。

创建完成后，下拉框组件包含1个button控制器、1个文本组件和1组图片(图形)：
1. button控制器：下拉框的主体功能，即单选按钮。
2. title：文本组件，即单选按钮的标题。
3. 其他图片(图形)，对应单选按钮各状态显示的图片或图形。

“popup”组件包含1个图片(图形)和1个列表，默认关联内部的列表高度：
1. 图片或图形为popup组件背景，默认关联容器的宽和高，随容器尺寸一同变换。
2. list：按钮列表，默认元素为“item”按钮，默认关联容器的宽。

“item”按钮是一个普通按钮，但内部所有元素都默认关联容器的宽和高，随容器尺寸一同变换。

## 下拉框设计

在创建下拉框阶段，根据提示设置好各个图片，就已完成下拉框的大部分设计工作。
下拉框自身属性只有一个**弹出组件**选项，建议非必要不修改该项。
其他的设计工作在FairyGUI编辑器舞台中完成。

## FairyGUI编辑器舞台的下拉框属性

在其他普通组件的编辑舞台中，可以直接拖入设计完成的下拉框组件，生成一个下拉框实例。FairyGUI的下拉框实例具有下拉框实例属性。
![按下拉框实例属性](screenshots\fguieditor\combobox_attributes.png)

### 标题

如果下拉框内部有名为*title*的文本控件，那直接修改实例属性中的标题后，下拉框按钮显示的文本也会发生改变。
此项对应转换后Ren'Py下拉框按钮界面定义中的*title*参数。下拉框弹出组件列表中的按钮点击后，此处显示的文本会替换为被点击按钮的标题文本。

### 标题颜色

这项不会被UI资源转换器处理。

### 图标

UI资源转换器仅处理使用图片作为图标的情况。此项对应转换后Ren'Py按钮界面定义中的*icon*参数。

### 可见项目数

列表最多显示的项目数量。UI资源转换器会根据该项和item按钮的高度计算弹出转换后的viewport尺寸。

### 弹出方向

决定弹出列表显示在按钮下方还是按钮上方。UI资源转换器**不支持“自动”选项**的效果，选择“自动”等同于“向下”。

### 点击音效

此项对应转换后Ren'Py按钮界面定义中的*activate_sound*参数。*音量*不会被UI资源转换器处理。

### 选择控制

若下拉框关联了组件控制器，则点击弹出列表按钮后，将根据按钮在列表中的索引修改下拉框实例所属组件的对应控制器索引。

!!! notice "控制器页面数量需要与下列框选项数量匹配"

    FairyGUI不强制要求下拉框的选项数量不大于关联控制器页面数量。当下拉框选项总数大于控制器最大索引时，效果等同于控制器页面设置为最大索引。
    例如，某个组件中设置了名为“index_controller”的控制且包含4个页面。组件中名为“index_selector”的下拉框包含6个按钮，且**选择控制**项关联了“index_controller”。
    点击下拉框的前4个按钮可以切换“index_controller”对应索引号的页面，点击后2个按钮则固定切换为索引号为3(最大索引)的页面。
    UI资源转换器在生成的Ren'Py代码中也针对**控制器页面数量需要与下列框选项数量不匹配**的情况做了处理，但下拉列表中的按钮状态可能会有显示问题。
    我们建议在设计阶段就排除两者数量不匹配的可能性。

### 编辑列表项目

可以添加和删除弹出列表的按钮数量，并可以设置各按钮的文本标题。UI资源转换器暂不处理*图标*和*值*两项。
