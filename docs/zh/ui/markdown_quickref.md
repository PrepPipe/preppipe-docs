# Markdown 语法简要说明

本文提供常用 Markdown 语法的简要参考，适合快速查阅。

# 标题
使用 `#` 到 `######` 表示 1-6 级标题。

# 段落与换行
空一行开始新段落，行尾两个空格可强制换行。

# 强调
说斜体、加粗与删除线的写法。

# 列表
无序、有序与任务列表的基本写法。

# 链接与图片
链接与图片的常用语法和路径用法。

# 引用
使用 `>` 表示引用与嵌套引用。

# 代码
行内代码与代码块的写法，代码块可注明语言。

# 表格
Markdown 表格的基本写法与分隔线。

# 分割线
使用 `---` 生成分割线。

# 转义
使用反斜杠转义特殊符号。

# HTML
可直接嵌入简单 HTML 以实现更丰富的效果。
